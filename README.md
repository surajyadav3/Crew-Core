# CrewCore

A premium React Native application built with Expo and Expo Router.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npx expo start
   ```

## Project Structure

- `app/`: Contains the application routes (Expo Router).
- `hooks/`: Custom React hooks.
- `constants/`: Theme constants and configuration.
- `assets/`: Images, fonts, and other static files.

## Features

- **Expo Router**: Modern file-based navigation.
- **TypeScript**: Typed development for better DX.
- **Premium UI**: Sleek dark mode design.
